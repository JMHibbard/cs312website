This website is a project for my CS312 class at the University of Alabama. The purpose of this website is to demonstrate my knowledge of HTML and CSS, as well as to provide information about my project on bird classification using machine learning. I am excited to learn more about web development and how it can be used in conjunction with machine learning. I hope to create a website that is both informative and visually appealing. I am looking forward to the challenges and opportunities that this project will bring.
